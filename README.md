# 保单现价与 IRR 智能分析工具 · 试用说明

本仓库在 `BX\IRR and SI` 目录下提供 **单文件 Web 小工具**（`insurance_yield_tool.html`），在浏览器中解析保险公司出具的 **保单演示 Excel**，结合您录入的 **缴费年期、各年折扣、预缴优惠** 等信息，自动计算各保单年度的 **复利收益率** 与 **单利收益率**，并支持将结果 **导出为带样式的 Excel**，便于复核与留档。

> **说明**：当前版本的核心逻辑均在页面内的 JavaScript 中完成，**不依赖** 项目内额外的 Python 分析脚本。若您希望用命令行启动本地服务再打开页面（部分环境下可避免 `file://` 带来的限制），可使用下文「可选：Python 本地服务」一节中的命令。

---

## 一、核心功能

| 能力 | 说明 |
|------|------|
| **续缴年期与名义保额** | 录入 **名义保额**、**缴费年限（年）**，作为后续「年缴份额」与现金流折算的基础。 |
| **各年折扣** | 支持 **无折扣**（一键将各年折扣置为 0%），或按年录入 **折扣率（%）**；实缴保费按「名义保额 ÷ 缴费年限 × (1 − 该年折扣%)」参与计算。 |
| **预缴模式** | 可选 **不预缴** / **预缴**，预缴时录入 **预缴优惠（%）**；工具按既定公式将预缴折算为 **一次性保费**，并参与收益率现金流。 |
| **演示模式：不提取 / 提取** | **不提取**：从演示表 **E 列** 读取「预期保单现价」。**提取**：现价 = **K 列（累计提取金额）+ G 列（提取后剩余价值）**；收益率仍按该合计现价与保费现金流计算。切换模式会清空已有结果，需重新计算。 |
| **现价与 IRR** | 按演示表年度与现价序列，结合保费流计算各年 **复利收益率**、**单利收益率**；右侧表格展示结果，并可 **导出 Excel**（含工具名、作者及版式）。 |
| **单文件分发** | 表格库 **已内嵌在 HTML** 中，iPhone「文件」里只拷贝一个 HTML 即可使用（无需同目录 `xlsx.min.js`）。头像等资源已内嵌时，无需再附带图片文件。 |

> 关于 **「预期总现价倍数」**：本工具直接输出的是 **分年度预期保单现价** 与 **复利/单利收益率**。若您习惯用「现价 ÷ 累计实缴保费」等倍数口径，可在导出后的 Excel 中自行增列，或对照页面中的现价与保费逻辑进行核对。

## 二、使用步骤

### 1. 准备演示表与目录

1. 将保险公司提供的 **保单演示表**（`.xlsx` 或 `.xls`）放入本机任意位置；为便于管理，建议与工具放在同一目录，例如：  
   `BX\IRR and SI\`  
   （与 `insurance_yield_tool.html` 同文件夹，方便查找与备份。）
2. 确认表中至少包含工具要求的列（页面「保单演示文件」区域有简要说明）：  
   - **A 列**：保单年度（如「1年」「1岁」等可解析格式）。  
   - **不提取**：**E 列** 为预期保单现价。  
   - **提取**：**K 列**、**G 列** 参与现价合计，含义见页面内说明。

### 2. 用浏览器打开工具页面

**方式 A（最简单）**  

- 在资源管理器中进入 `BX\IRR and SI\`，**双击** `insurance_yield_tool.html`，用默认浏览器打开。

**方式 B（推荐：本地 HTTP 服务，可选）**  

若您更习惯通过 `http://localhost` 访问（或双击打开遇到脚本/缓存异常时），可在项目根目录或 `BX\IRR and SI` 下打开终端，执行：

```powershell
cd "BX\IRR and SI"
python -m http.server 8765
```

然后在浏览器地址栏访问：

```text
http://localhost:8765/insurance_yield_tool.html
```

> **表格库**：`xlsx-js-style` 已 **写入 HTML 内的 `<script>`**，避免 iOS「文件」打开本地页时 **禁止加载同目录外部 `.js`** 导致 `XLSX` 未定义。仓库中仍保留 `xlsx.min.js` 作为升级表格库时的源文件；**转发给他人时只需发送 HTML**。

### 3. 在页面中完成计算

1. **基本参数**：填写名义保额、缴费年限；按需勾选「无折扣」，点击 **「确认」**（若未勾选无折扣，将按年录入各年折扣）。  
2. **预缴设置**：选择不预缴或预缴，预缴时填写预缴优惠百分比。  
3. **演示模式**：选择「不提取」或「提取」（与 Excel 列约定一致）。  
4. **上传文件**：将演示表 **拖拽到上传区** 或点击选择文件。  
5. 点击 **「开始计算」**，在右侧 **「计算结果」** 查看表格；需要时使用 **「导出到 Excel」**。

### 4. 查看「美化后的 HTML 结果」

- 计算结果即渲染在 **当前页面右侧** 的表格区域中（版式、颜色与页头样式均为页面内置）。  
- **无需**再运行其他程序生成 HTML；保存页面或导出 Excel 即可留档。

## 三、试用反馈注意事项

为便于收集有效反馈、快速复现问题，建议您在反馈时尽量包含以下信息：

1. **环境与入口**  
   - 操作系统与浏览器类型、版本（例如 Windows 11 + Edge 130）。  
   - 打开方式是 **双击本地文件** 还是 **`python -m http.server`**。

2. **参数与数据**  
   - 名义保额、缴费年限、是否无折扣、预缴与否及预缴优惠百分比。  
   - 演示模式为「不提取」还是「提取」。  
   - 演示表来源（保司/产品类型即可，无需泄露客户隐私）；若可能，说明 **A / E / K / G 列** 是否与工具约定一致。

3. **现象描述**  
   - 是 **无法加载表格**、**计算报错**、**结果与手工验算不符**，还是 **导出 Excel 版式/列错位** 等。  
   - 如有报错提示或控制台错误（F12 → Console），可截图或复制文字。

4. **边界与免责**  
   - 本工具用于 **演示数据下的收益率辅助分析**，不构成投保建议或法律/税务意见。  
   - 不同保司演示表版式差异较大，若列名或结构特殊，请先对照页面说明调整表结构或反馈给维护者以便扩展规则。
